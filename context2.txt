Each hairpin resonator is modelled as a shunt open-ended λ/2 stub:
  Yin = tanh(γL) / Z0_s

At fc (lossless): γL = jβL = jπ  →  tanh(jπ) = j·tan(π) = 0  → Yin=0 (OPEN)
This is correct parallel-resonator behaviour.

Cascade:
  Port1 (50Ω) → J[0,1] → [shunt Res1] → J[1,2] → [shunt Res2]

def chebyshev_g(N, Ar):
    beta  = np.log(1 / np.tanh(Ar / 17.37))
    gamma = np.sinh(beta / (2*N))
    g = np.zeros(N+2);  g[0] = 1.0
    g[1] = 2*np.sin(np.pi/(2*N)) / gamma
    for k in range(2, N+1):
        g[k] = (4*np.sin((2*k-1)*np.pi/(2*N))*np.sin((2*k-3)*np.pi/(2*N))
                / (gamma**2 + np.sin((k-1)*np.pi/N)**2) / g[k-1])
    g[N+1] = 1.0 if N%2==1 else (1/np.tanh(beta/4))**2
    return g

# ── Microstrip propagation model ───────────────────────────────────────────
def er_eff_static(W, er, h):
    W_h = W/h
    F = 1/np.sqrt(1+12/W_h) if W_h > 1 else 1/np.sqrt(1+12/W_h) + 0.04*(1-W_h)**2
    return (er+1)/2 + (er-1)/2*F

def Z0_ms(W, er, h):
    W_h  = W/h
    er_s = er_eff_static(W, er, h)
    if W_h <= 1:
        return 60/np.sqrt(er_s) * np.log(8/W_h + W_h/4)
    return 120*np.pi / (np.sqrt(er_s)*(W_h + 1.393 + 0.667*np.log(W_h+1.444)))

def propagation_const(W, er, h, t, tand, sigma, f):
    er_s = er_eff_static(W, er, h)
    Z0_s = Z0_ms(W, er, h)
    fn   = f * h
    er_f = er - (er-er_s) / (1 + 0.0004*(fn/7.5e9)**2.32)
    er_f = max(er_f, er_s)
    beta = 2*np.pi*f*np.sqrt(er_f) / c0
    mu0  = 4e-7*np.pi
    Rs   = np.sqrt(np.pi*f*mu0 / sigma)
    Weff = W + t/np.pi*(1 + np.log(2*h/t))
    alpha_c = Rs / (Z0_s * max(Weff, 1e-9))
    alpha_d = np.pi*f/c0 * er*(er_f-1)*tand / (np.sqrt(er_f)*(er-1) + 1e-30)
    return alpha_c + alpha_d + 1j*beta, Z0_s

# ── ABCD building blocks ───────────────────────────────────────────────────
def J_inv_ABCD(J_val):
    """Ideal admittance inverter."""
    return np.array([[0+0j,       1j/J_val],
                     [1j*J_val,   0+0j]])

def shunt_res_ABCD(f):
    """
    Shunt open-ended λ/2 stub (the parallel resonator).
    Yin = tanh(γL) / Z0_s
    At fc (lossless): tanh(jπ) = 0  →  ABCD = identity  ✓
    """
    gamma, Z0_s = propagation_const(W50, er, h, t, tand, sigma, f)
    Yin = np.tanh(gamma * L_res) / Z0_s
    return np.array([[1+0j, 0+0j],
                     [Yin,  1+0j]])

def ABCD_to_S(M, Z0=50.0):
    A, B, C, D = M[0,0], M[0,1], M[1,0], M[1,1]
    den = A + B/Z0 + C*Z0 + D
    return np.array([[(A + B/Z0 - C*Z0 - D)/den,  2*(A*D - B*C)/den],
                     [           2.0/den,           (-A + B/Z0 - C*Z0 + D)/den]])

def compute_S(freq_arr):
    S11a = np.zeros(len(freq_arr), dtype=complex)
    S21a = np.zeros(len(freq_arr), dtype=complex)
    for k, f in enumerate(freq_arr):
        M = J_inv_ABCD(J[0])
        for i in range(N):
            M = M @ shunt_res_ABCD(f) @ J_inv_ABCD(J[i+1])
        S = ABCD_to_S(M)
        S11a[k] = S[0,0];  S21a[k] = S[1,0]
    return S11a, S21a

The topology is now correct - lossless gives 0 dB at fc. But the lossy case gives -44 dB, which means the loss model is absurdly high. 44 dB of insertion loss from FR4 tanδ=0.02 at 868 MHz is physically impossible.

The issue: the shunt open-ended λ/2 stub model. An open stub at resonance (βL = π) has Yin = tanh(γL)/Z0_s. With loss:

    γ = α + jβ
    γL = αL + jπ

tanh(αL + jπ) = tanh(αL + jπ)

Since tanh(x + jπ) = tanh(x) (period π in imaginary part):
tanh(γL) = tanh(αL + jπ) = tanh(αL)

So Yin ≈ tanh(αL)/Z0_s ≈ αL/Z0_s (for small αL)

This is a small real conductance representing loss - that's correct. But wait, why is S21 = -44 dB?

Let me think... the problem might be that I'm using the full L_res = 94.7 mm for each of the 5 shunt stubs, which is a lot of loss. But that shouldn't give 44 dB.

Let me compute: αL for FR4 at 868 MHz:

    Dielectric loss: α_d ≈ πf/c0 * er(er_f-1)tand/(sqrt(er_f)(er-1))
    ≈ π868e6/3e8 * 4.4(3.33-1)0.02/(sqrt(3.33)(4.4-1))
    ≈ 9.09 * 4.42.330.02/(1.825*3.4)
    ≈ 9.09 * 0.2051/6.205
    ≈ 9.09 * 0.0331
    ≈ 0.30 Np/m

αL = 0.30 * 0.09469 m ≈ 0.028 Np ≈ 0.24 dB per resonator

For 5 resonators: ~1.2 dB total loss. That's well within the 2 dB spec.

But I'm getting -44 dB. Something else is wrong.

Wait - the issue might be that at fc, with complex γ:
γL = αL + jβL = αL + jπ

tanh(αL + jπ) = sinh(αL + jπ)/cosh(αL + jπ)
= (sinh(αL)cos(π) + jcosh(αL)sin(π)) / (cosh(αL)cos(π) + jsinh(αL)sin(π))
= (-sinh(αL)) / (-cosh(αL))
= tanh(αL)

So Yin at fc = tanh(αL)/Z0_s ≈ 0.028/50 = 0.00056 S

This is a small conductance per resonator. The J_ext = 0.002512 S.

The shunt resonator now has Yin ≈ 0.00056 S at fc (real), which is not zero. This means the resonator is presenting a shunt conductance, which loads the circuit and causes loss.

Actually, the -44 dB makes physical sense if the resonator unloaded Q is:
Qu = b/G = (π*Y0/2) / (αL * Y0/Z0_s)

# Microstrip propagation model
def er_eff_static(W, er, h):
    W_h = W/h
    F = 1/np.sqrt(1+12/W_h) if W_h > 1 else 1/np.sqrt(1+12/W_h) + 0.04*(1-W_h)**2
    return (er+1)/2 + (er-1)/2*F

def Z0_ms(W, er, h):
    W_h  = W/h
    er_s = er_eff_static(W, er, h)
    if W_h <= 1:
        return 60/np.sqrt(er_s) * np.log(8/W_h + W_h/4)
    return 120*np.pi / (np.sqrt(er_s)*(W_h + 1.393 + 0.667*np.log(W_h+1.444)))

def propagation_const(W, er, h, t, tand, sigma, f):
    er_s = er_eff_static(W, er, h)
    Z0_s = Z0_ms(W, er, h)
    fn   = f * h
    er_f = max(er - (er-er_s) / (1 + 0.0004*(fn/7.5e9)**2.32), er_s)
    beta = 2*np.pi*f*np.sqrt(er_f) / c0

# g-values
def chebyshev_g(N, Ar):
    beta  = np.log(1 / np.tanh(Ar / 17.37))
    gamma = np.sinh(beta / (2*N))
    g = np.zeros(N+2);  g[0] = 1.0
    g[1] = 2*np.sin(np.pi/(2*N)) / gamma
    for k in range(2, N+1):
        g[k] = (4*np.sin((2*k-1)*np.pi/(2*N))*np.sin((2*k-3)*np.pi/(2*N))
                / (gamma**2 + np.sin((k-1)*np.pi/N)**2) / g[k-1])
    g[N+1] = 1.0 if N%2==1 else (1/np.tanh(beta/4))**2
    return g

# Microstrip propagation model
def er_eff_static(W, er, h):
    W_h = W/h
    F = 1/np.sqrt(1+12/W_h) if W_h > 1 else 1/np.sqrt(1+12/W_h) + 0.04*(1-W_h)**2
    return (er+1)/2 + (er-1)/2*F

def Z0_ms(W, er, h):
    W_h  = W/h
    er_s = er_eff_static(W, er, h)
    if W_h <= 1:
        return 60/np.sqrt(er_s) * np.log(8/W_h + W_h/4)
    return 120*np.pi / (np.sqrt(er_s)*(W_h + 1.393 + 0.667*np.log(W_h+1.444)))

def propagation_const(W, er, h, t, tand, sigma, f):
    er_s = er_eff_static(W, er, h)
    Z0_s = Z0_ms(W, er, h)
    fn   = f * h
    er_f = max(er - (er-er_s) / (1 + 0.0004*(fn/7.5e9)**2.32), er_s)
    beta = 2*np.pi*f*np.sqrt(er_f) / c0
    mu0  = 4e-7*np.pi
    Rs   = np.sqrt(np.pi*f*mu0 / sigma)
    Weff = W + (t/np.pi*(1 + np.log(2*h/t)) if t > 0 else 0)
    alpha_c = Rs / (Z0_s * max(Weff, 1e-9))
    alpha_d = np.pi*f/c0 * er*(er_f-1)*tand / (np.sqrt(er_f)*(er-1) + 1e-30)
    return alpha_c + alpha_d + 1j*beta, Z0_s

# ABCD blocks
def J_inv_ABCD(J_val):
    return np.array([[0+0j, 1j/J_val],
                     [1j*J_val, 0+0j]])

def shunt_res_ABCD(f, tand_=None, sigma_=None):
    """Shunt open-ended λ/2 stub.  Yin = tanh(γL)/Z0_s"""
    td = tand_ if tand_ is not None else tand
    sg = sigma_ if sigma_ is not None else sigma
    gamma, Z0_s = propagation_const(W50, er, h, t, td, sg, f)
    Yin = np.tanh(gamma * L_res) / Z0_s
    return np.array([[1+0j, 0+0j], [Yin, 1+0j]])

def ABCD_to_S(M, Z0=50.0):
    A, B, C, D = M[0,0], M[0,1], M[1,0], M[1,1]
    den = A + B/Z0 + C*Z0 + D
    return np.array([[(A + B/Z0 - C*Z0 - D)/den,  2*(A*D-B*C)/den],
                     [2.0/den,  (-A + B/Z0 - C*Z0 + D)/den]])

# Sweep
def compute_S(freq_arr, **kw):
    S11a = np.zeros(len(freq_arr), dtype=complex)
    S21a = np.zeros(len(freq_arr), dtype=complex)
    for k, f in enumerate(freq_arr):
        M = J_inv_ABCD(J[0])
        for i in range(N):
            M = M @ shunt_res_ABCD(f, **kw) @ J_inv_ABCD(J[i+1])
        S = ABCD_to_S(M)
        S11a[k] = S[0,0];  S21a[k] = S[1,0]
    return S11a, S21a

def write_s2p(path, freqs, S11, S21, z0=50.0):
    """Write Touchstone 1.0 .s2p (RI format, 50-ohm)."""
    lines = [
        "! Hairpin BPF Stage 2 — auto-generated",
        "# Hz S RI R 50",
    ]
    for f, s11, s21 in zip(freqs, S11, S21):
        # S-matrix (reciprocal, symmetric): S11, S21, S12=S21, S22=S11
        lines.append(
            f"{f:.6e}  "
            f"{s11.real:.8f} {s11.imag:.8f}  "
            f"{s21.real:.8f} {s21.imag:.8f}  "
            f"{s21.real:.8f} {s21.imag:.8f}  "
            f"{s11.real:.8f} {s11.imag:.8f}"
        )
    with open(path, "w") as fh:
        fh.write("\n".join(lines) + "\n")

modelled (Stage 3).

# ═══════════════════════════════════════════════════════════════
# DESIGN PARAMETERS
# ═══════════════════════════════════════════════════════════════
c0    = 3e8          # speed of light (m/s)
fc    = 868e6        # centre frequency (Hz)
BW    = 10e6         # 3-dB bandwidth (Hz)
FBW   = BW / fc      # fractional bandwidth
Z0    = 50.0         # port impedance (Ω)
Y0    = 1.0 / Z0
N     = 5            # filter order (FIXED — manufacturing constraint)
Ar    = 0.1          # passband ripple (dB)

# FR4 substrate (FIXED — cost constraint)
er    = 4.4          # relative permittivity
h     = 1.6e-3       # substrate height (m)
t     = 35e-6        # copper thickness (m)  [1 oz]
tand  = 0.020        # loss tangent at 868 MHz
sigma = 5.8e7        # copper conductivity (S/m)

# Microstrip dimensions (from Stage 1 synthesis)
W50   = 3.0590e-3    # 50-Ω line width (m)
L_res = 94.6969e-3   # λ/2 resonator length (m) — each leg = L_res/2

# Coupling gaps from Stage 1 (input/output first, then interior pairs)
# gap[0] = between port and resonator 1
# gap[1] = between resonator 1 and 2
# gap[2] = between resonator 2 and 3  (symmetric so gap[2]=gap[1])
# gap[3] = between resonator 4 and 5  (= gap[0] by symmetry)
gaps_mm = [2.472, 2.649, 2.649, 2.472]   # mm

# ═══════════════════════════════════════════════════════════════
# CHEBYSHEV G-VALUES
# ═══════════════════════════════════════════════════════════════
def chebyshev_g(N, Ar):
    beta  = np.log(1.0 / np.tanh(Ar / 17.37))
    gamma = np.sinh(beta / (2.0 * N))
    g = np.zeros(N + 2)
    g[0] = 1.0
    g[1] = 2.0 * np.sin(np.pi / (2.0 * N)) / gamma
    for k in range(2, N + 1):
        num = 4.0 * np.sin((2*k-1)*np.pi/(2*N)) * np.sin((2*k-3)*np.pi/(2*N))
        den = (gamma**2 + np.sin((k-1)*np.pi/N)**2) * g[k-1]
        g[k] = num / den
    g[N+1] = 1.0 if N % 2 == 1 else (1.0 / np.tanh(beta / 4.0))**2
    return g

g   = chebyshev_g(N, Ar)
Qe  = g[0] * g[1] / FBW                           # external Q
M   = np.array([FBW / np.sqrt(g[i+1]*g[i+2])
                for i in range(N-1)])              # coupling coefficients
b   = np.pi * Y0 / 2.0                            # susceptance slope (λ/2 res)

# ═══════════════════════════════════════════════════════════════
# J-INVERTER ADMITTANCES  (Hong & Lancaster Ch.8)
# ═══════════════════════════════════════════════════════════════
J_ext = np.sqrt(b * Y0 / Qe)
J_int = M * b
J     = np.concatenate([[J_ext], J_int, [J_ext]])  # length N+1

# ═══════════════════════════════════════════════════════════════
# MICROSTRIP PROPAGATION MODEL
# ═══════════════════════════════════════════════════════════════
def er_eff_static(W, er, h):
    u = W / h
    if u > 1:
        F = 1.0 / np.sqrt(1.0 + 12.0/u)
    else:
        F = 1.0 / np.sqrt(1.0 + 12.0/u) + 0.04*(1.0 - u)**2
    return (er + 1)/2.0 + (er - 1)/2.0 * F

def Z0_microstrip(W, er, h):
    u    = W / h
    er_s = er_eff_static(W, er, h)
    if u <= 1:
        return 60.0 / np.sqrt(er_s) * np.log(8.0/u + u/4.0)
    return 120.0*np.pi / (np.sqrt(er_s) * (u + 1.393 + 0.667*np.log(u + 1.444)))

def propagation_const(W, er, h, t, tand, sigma, f):
    er_s = er_eff_static(W, er, h)
    Z0_s = Z0_microstrip(W, er, h)
    # Dispersion (Kirschning & Jansen simplified)
    fn   = f * h   # normalised frequency
    er_f = max(er - (er - er_s) / (1.0 + 0.0004*(fn/7.5e9)**2.32), er_s)
    beta = 2.0*np.pi*f*np.sqrt(er_f) / c0
    # Conductor loss (surface resistance)
    mu0  = 4e-7*np.pi
    Rs   = np.sqrt(np.pi * f * mu0 / sigma)
    Weff = W + t/np.pi * (1.0 + np.log(2.0*h/t)) if t > 0 else W
    alpha_c = Rs / (Z0_s * max(Weff, 1e-9))
    # Dielectric loss
    alpha_d = (np.pi*f/c0 * er*(er_f - 1)*tand
               / (np.sqrt(er_f)*(er - 1) + 1e-30))
    return (alpha_c + alpha_d + 1j*beta), Z0_s

# ═══════════════════════════════════════════════════════════════
# ABCD MATRIX PRIMITIVES
# ═══════════════════════════════════════════════════════════════
def J_inv_ABCD(J_val):
    """Ideal admittance inverter (lossless 90° coupler equivalent)."""
    return np.array([[0 + 0j,     1j/J_val],
                     [1j*J_val,   0 + 0j  ]])

def shunt_stub_ABCD(f, tand_=None, sigma_=None):
    """
    Shunt open-ended λ/2 stub.
    Parallel resonance at fc (Yin→0) when lossless.
    With loss: Yin = tanh(γL) / Z0_s
    """
    td = tand_  if tand_  is not None else tand
    sg = sigma_ if sigma_ is not None else sigma
    gamma, Z0_s = propagation_const(W50, er, h, t, td, sg, f)
    Yin = np.tanh(gamma * L_res) / Z0_s
    return np.array([[1 + 0j, 0 + 0j],
                     [Yin,    1 + 0j]])

def ABCD_to_S(M, Z0=50.0):
    A, B, C, D = M[0,0], M[0,1], M[1,0], M[1,1]
    den = A + B/Z0 + C*Z0 + D
    S11 = (A + B/Z0 - C*Z0 - D) / den
    S21 = 2.0 / den
    S12 = 2.0*(A*D - B*C) / den
    S22 = (-A + B/Z0 - C*Z0 + D) / den
    return np.array([[S11, S12], [S21, S22]])

# ═══════════════════════════════════════════════════════════════
# TOPOLOGY SANITY CHECK (lossless at fc)
# ═══════════════════════════════════════════════════════════════
gam_ll, Z0_s = propagation_const(W50, er, h, 0, 0, 1e20, fc)
Yin_fc = np.tanh(gam_ll * L_res) / Z0_s

# For lossless check: resonators open → pass-through identity
M_fc = J_inv_ABCD(J[0])
for i in range(N):
    # At fc (lossless), shunt Yin≈0 → identity matrix
    M_fc = M_fc @ np.eye(2, dtype=complex) @ J_inv_ABCD(J[i+1])
S_fc_ll = ABCD_to_S(M_fc)

# ═══════════════════════════════════════════════════════════════
# FREQUENCY SWEEP
# ═══════════════════════════════════════════════════════════════
def sweep(freqs, tand_=None, sigma_=None):
    S11a = np.empty(len(freqs), dtype=complex)
    S21a = np.empty(len(freqs), dtype=complex)
    for k, f in enumerate(freqs):
        Mc = J_inv_ABCD(J[0])
        for i in range(N):
            Mc = Mc @ shunt_stub_ABCD(f, tand_, sigma_) @ J_inv_ABCD(J[i+1])
        S = ABCD_to_S(Mc)
        S11a[k] = S[0,0]
        S21a[k] = S[1,0]
    return S11a, S21a

freq_Hz = np.linspace(700e6, 1050e6, 2801)

S11,    S21    = sweep(freq_Hz)                      # lossy FR4
S11_ll, S21_ll = sweep(freq_Hz, tand_=0, sigma_=1e20)  # lossless ref

S11_dB    = 20*np.log10(np.maximum(np.abs(S11),    1e-12))
S21_dB    = 20*np.log10(np.maximum(np.abs(S21),    1e-12))
S11_ll_dB = 20*np.log10(np.maximum(np.abs(S11_ll), 1e-12))
S21_ll_dB = 20*np.log10(np.maximum(np.abs(S21_ll), 1e-12))

# ═══════════════════════════════════════════════════════════════
# METRICS

                 np.cos (N * np.arccos (np.clip(Om, -1, 1))))

def write_s2p(path, freqs, S11, S21, z0=50.0):
    lines = [
        "! Hairpin BPF N=5 fc=868MHz BW=10MHz FR4 — Stage 2 circuit model",
        f"! Generated by stage2_final.py",
        "# Hz S RI R 50",
    ]
    for f, s11, s21 in zip(freqs, S11, S21):
        lines.append(
            f"{f:.6e}  "
            f"{s11.real: .8f} {s11.imag: .8f}  "
            f"{s21.real: .8f} {s21.imag: .8f}  "
            f"{s21.real: .8f} {s21.imag: .8f}  "
            f"{s11.real: .8f} {s11.imag: .8f}"
        )
    with open(path, "w") as fh:
        fh.write("\n".join(lines) + "\n")

can i skip the qucs and go directly to openems?

Yes, and honestly for a manufacturable hairpin filter this is the better path — QUCS-S's quasi-static microstrip models still miss the real coupled-line field behavior at the gaps, which is exactly the thing that matters most in a hairpin filter. A full 3D FEM/FDTD solver like openEMS captures that directly from your physical geometry instead of approximating it with formulas.

A few things worth knowing before you commit to that route:

What changes about the workflow

    QUCS-S works from idealized transmission-line components (MLIN, MCOUPLED) where you type in W/L/S and it computes S-parameters analytically/quasi-statically.
    openEMS works from an actual 3D mesh of your copper geometry, substrate, and ports — it's a real FDTD electromagnetic simulation. You define the structure as a CSX (geometry) script, set up ports and an excitation, run the time-domain solver, then post-process to get S-parameters.
    This means you skip schematic capture entirely — you go straight from your Stage 2 dimensions (arm lengths, gaps, W, substrate) into a Python or Octave/MATLAB script that builds the physical layout.

What you'll need

    openEMS + AppCSXCAD (for visualizing the mesh) — typically run via the openEMS Python bindings (pyems or the openEMS-Project Python interface) or Octave scripts. Python is more common now.
    A mesh strategy — hairpin filters need a fine enough mesh at the coupling gaps (sub-0.1mm cell size near the gaps) but FDTD cost scales fast with cell count, so meshing the gaps tightly while keeping the rest coarse matters a lot for runtime.
    Patience on first run — openEMS simulations for a 5-resonator filter at 868 MHz will likely take anywhere from several minutes to an hour depending on your mesh and CPU, versus QUCS-S's near-instant circuit solve.
